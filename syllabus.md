## 🎯 Мета курсу та цільова аудиторія

### Мета курсу
Сформувати в учасників практичні навички програмування мовою Python, необхідні для подальшого стажування або працевлаштування в ІТ-сфері.

Курс побудований за принципом поступового ускладнення: від базових понять програмування, синтаксису Python, типів даних, умовних конструкцій, циклів, функцій і роботи з колекціями — до об’єктно-орієнтованого програмування, роботи з файлами, модулями, пакетами. Учасники опановують роботу з базами даних, PostgreSQL та створення веб-застосунків на Django.

У межах курсу учасники застосовують знання на практиці: налаштовують середовище розробки, працюють із GitHub, створюють Python-скрипти, виконують практичні завдання, працюють із даними, базами даних, HTTP-запитами, API та розробляють навчальні проєкти.

### Цільова аудиторія
* Початківці без попереднього досвіду в програмуванні;

## 📝 Короткий опис структури курсу

Програма послідовно охоплює такі ключові технологічні блоки:
1.  **Основи Python та Git:** налаштування середовища (VS Code, `uv`), базовий синтаксис, структури даних, робота з репозиторіями GitHub.
2.  **Об'єктно-Орієнтоване Програмування (ООП):** класи, магічні методи, MRO, інкапсуляція, декоратори, ітератори та генератори, обробка помилок та логування.
3.  **Робота з даними та мережею:** формати JSON/CSV, локальні БД (SQLite), функціональне програмування, робота з сокетами, HTTP-запити (`requests`), розробка Telegram-ботів, асинхронне програмування та тестування (`pytest`).
4.  **Професійна робота з PostgreSQL:** проєктування реляційних баз даних, нормалізація (1NF, 2NF, 3NF), комплексні SQL-запити (JOIN, віконні функції, представлення, збережені процедури).
5.  **Веб-розробка на Django та DRF:** розробка веб-застосунків (MVC/MVT), Django ORM, автентифікація та сесії, побудова REST API за допомогою Django REST Framework, JWT, документація Swagger, безпека застосунків та деплой (WSGI/ASGI, Gunicorn).

## 🎓 Результати навчання (Ключові компетенції випускника)

Після завершення курсу учасники зможуть:
* **Розробляти скрипти та програми:** писати чистий Python-код з дотриманням стандарту PEP8, ефективно використовувати змінні, функції, цикли, умовні конструкції та рекурсію.
* **Керувати версіями коду:** професійно працювати з Git та GitHub, налаштовувати локальні й віддалені репозиторії, створювати гілки, робити коміти та мерджити код.
* **Застосовувати ООП:** проєктувати архітектуру застосунків на основі класів, об'єктів, спадкування, поліморфізму, інкапсуляції, абстрактних класів та магічних методів.
* **Ефективно керувати проєктами:** ізолювати залежності за допомогою віртуальних середовищ (`venv`, `uv`), структурувати пакети й модулі, налаштовувати логування та обробляти винятки.
* **Працювати з даними:** виконувати серіалізацію/десеріалізацію у JSON та CSV, здійснювати складну валідацію за допомогою регулярних виразів (`re`).
* **Проєктувати та інтегрувати БД:** створювати бази даних у SQLite та PostgreSQL, писати складні SQL-запити (JOIN, підзапити, віконні функції, представлення, DDL-команди), взаємодіяти з БД через Python.
* **Програмувати мережеві інструменти:** виконувати HTTP-запити через бібліотеку `requests`, створювати клієнт-серверні сокет-застосунки, розробляти синхронні та асинхронні Telegram-боти, створювати веб-скрапери (`BeautifulSoup`).
* **Розробляти веб-застосунки:** створювати повноцінні сайти на Django, налаштовувати маршрутизацію, шаблони, форми, моделі, систему автентифікації користувачів, сесії та адмін-панель.
* **Будувати API:** проектувати та створювати REST API через Django REST Framework (DRF) з підтримкою токенів, JWT-автентифікації, дозволів та інтегрувати документацію Swagger.
* **Тестувати та захищати код:** покривати модулі тестами за допомогою `pytest` та `pytest-django`, а також налаштовувати захист від XSS, CSRF та SQL-ін'єкцій.
* **Деплоїти застосунки:** готувати та оптимізувати Django-застосунки для продуктового середовища (Production) з використанням специфікацій WSGI та ASGI.
